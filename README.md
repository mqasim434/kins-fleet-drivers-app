# KINS Fleet Chauffeur (Drivers App)

Flutter mobile app for KINS Logistics chauffeurs. Connects to the same Firebase project as the [KINS Fleet Admin](https://github.com/) web dashboard (`kins-fleet-app`).

## Prerequisites

- Flutter 3.x (stable), Dart 3.x
- Firebase CLI: `npx -y firebase-tools@latest login`
- FlutterFire CLI: `dart pub global activate flutterfire_cli`

## Firebase setup (already done)

This project is linked to Firebase project **`kins-fleet-app`**.

| Platform | Package / Bundle ID | Firebase App ID |
|----------|---------------------|-----------------|
| Android | `com.kins.logistics.driver` | `1:620579732627:android:472a5b45e12b9016b6a166` |
| iOS | `nl.kins.logistics.driver` | `1:620579732627:ios:a7b7cdcaef21b750b6a166` |

### Config files

- `.firebaserc` — project alias
- `firebase.json` — FlutterFire platform mapping
- `android/app/google-services.json` — Android config (downloaded via CLI)
- `ios/Runner/GoogleService-Info.plist` — iOS config (downloaded via CLI)
- `lib/firebase_options.dart` — Dart Firebase options (generated by FlutterFire)

### Re-run Firebase setup (if needed)

```bash
# Link project
npx -y firebase-tools@latest use kins-fleet-app

# Re-download platform configs
npx -y firebase-tools@latest apps:sdkconfig ANDROID 1:620579732627:android:472a5b45e12b9016b6a166 --project kins-fleet-app -o android/app/google-services.json
npx -y firebase-tools@latest apps:sdkconfig IOS 1:620579732627:ios:a7b7cdcaef21b750b6a166 --project kins-fleet-app -o ios/Runner/GoogleService-Info.plist

# Regenerate Dart options
flutterfire configure --project=kins-fleet-app --android-package-name=com.kins.logistics.driver --ios-bundle-id=nl.kins.logistics.driver --yes --platforms=android,ios
```

## Environment variables (ImageKit — Module 4+)

Copy `.env.json.example` to `.env.json` (gitignored) and fill in values:

```bash
flutter run --dart-define-from-file=.env.json
```

## Run

```bash
flutter pub get
flutter run
```

## Build

```bash
flutter build apk --release
flutter build appbundle --release
flutter build ios --release
```

## Accounts

Driver accounts are created by admin on the web dashboard — **no signup in this app**.

Test login requires a `users/{uid}` document with `role: driver`, `status: active`, and a linked `drivers/{driverId}` record.

## Firestore rules prerequisite

Driver read/write access must be deployed from the `kins-fleet-dashboard` repo before feature modules can access Firestore data:

```bash
firebase deploy --only firestore:rules
```
